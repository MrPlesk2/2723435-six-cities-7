# Сервисы базы данных

До задания были реализованы UserEntity/UserModel, OfferEntity/OfferModel и базовые методы создания и поиска.

| Сценарии | Модель и сервис | Методы |
| --- | --- | --- |
| Создание, изменение, удаление предложения | OfferModel, OfferService | create, updateById, deleteById |
| Списки и подробности, премиальные предложения | OfferModel, OfferService | find, findById, findPremium |
| Создание и список комментариев | Новые CommentEntity, CommentModel, CommentService | create, findByOfferId |
| Регистрация и поиск пользователя для авторизации | UserModel, UserService | create, findByEmail, findById |
| Избранное | UserModel, UserService; OfferService | addFavorite, removeFavorite, findFavorites |
| Обновление данных пользователя | UserModel, UserService | updateById |

Избранное хранится в существующем массиве пользователя; отдельная модель не нужна. Вход, выход и проверка сессии относятся к слою авторизации и не реализуются в сервисах базы данных этого задания.

Добавлены DTO создания комментария, изменения предложения и пользователя, изменения избранного и добавления оценки. Рейтинг исключён из CreateOfferDto и импорта: он не задаётся клиентом.

При создании комментария сервис атомарно увеличивает commentsCount и скрытую сумму оценок ratingSum в предложении, затем рассчитывает среднее с одним знаком после запятой. Для предложения без оценок используется 1, как в спецификации. Вычисление рейтинга не ограничивается последними 50 комментариями. Ошибка обновления статистики приводит к удалению созданного комментария.

Обновление и удаление предложения фильтруются одновременно по ID и автору. При удалении очищаются связанные комментарии и избранное. Добавление в избранное использует $addToSet и не создаёт дубликатов.

Операции над несколькими коллекциями не являются транзакцией. Сбой процесса между записями или одновременное удаление предложения требуют отдельного механизма транзакций/восстановления для строгой согласованности. Ранее импортированные рейтинги не учитываются как пользовательские оценки; первая новая оценка формирует рейтинг по новым комментариям.

Проверка: компиляция TypeScript, ESLint и tests/database-services.test.mjs (после компиляции проекта). Тесты используют подмены моделей и проверяют оркестрацию; интеграционная проверка требует работающей MongoDB.
